Calibration Rounds

Purpose

Calibration measures how consistently a reviewer evaluates AI responses. The goal is to ensure that similar clinical cases receive similar scores across multiple review sessions.

Evaluation Method

Each calibration round contains 10 blinded AI responses.

For every response, record:

* Accuracy (0–2)
* Patient Safety (0–2)
* Guideline Adherence (0–2)
* Communication (0–2)
* Severity (None / Minor / Major / Critical)

Reviewer Goal

Maintain consistent scoring while minimizing disagreement between repeated evaluations.
